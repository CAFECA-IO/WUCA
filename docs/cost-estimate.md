## 結論

| 項目 | 金額 |
| --- | --- |
| 一次性建置（全新） | NT$1,150–1,990 萬 |
| 一次性建置（沿用廠內既有線上分析儀） | NT$940–1,510 萬 |
| 每年維運 | NT$134–236 萬 |
| 建議招標預算（建置＋3 年維運，不含 WUCA 授權） | NT$1,340–2,700 萬 |

中央大腦佔建置費一半以上，其中 8 張 GPU 約 NT$340–384 萬。

**估算假設**：
- 規模：一個放流口、3 個處理區域（3 台 GB10）、重金屬線上監測 2 項（如銅、鋅）。
- 匯率：1 美元 ≈ NT$32（2026-08-07 收盤 32.288）。
- 不含 WUCA 軟體授權與稅。
- 標「※」者為編列估算，需以廠商報價替換。

## 政府污水廠招標行情

公開案例顯示，一座公共污水廠全廠新建動輒數億到數十億元，而監測或智慧化系統單獨招標多在數十萬到千萬元級。WUCA 單廠建置估算 NT$940–1,990 萬，與臺南「放流水自動連續監測建置工程」（1,700 萬）同一量級，約為小型廠全廠工程費的 2.5–5.3%。

### 建議招標預算（單廠）

| 項目 | 金額（萬元） | 說明 |
| --- | --- | --- |
| 建置（硬體＋工程） | 940–1,990 | 差距主要在既有分析儀可否沿用 |
| 3 年維運 | 400–710 | 每年 134–236 萬 |
| WUCA 軟體授權 | 待定 | CAFECA 定價 |
| **建議預算（不含授權）** | **1,340–2,700** | 公部門通常以「建置＋數年維運」一併發包 |

**採購程序**（[採購金額級距說明](https://www.general.ntust.edu.tw/var/file/54/1054/img/1918/619806283.pdf)）：
- 預算達公告金額 150 萬，需公開招標。
- 達查核金額需上級機關派員監辦：勞務採購 1,000 萬、工程或財物 5,000 萬。
- WUCA 屬財物＋勞務混合案，整案低於 5,000 萬；但若以勞務為主且超過 1,000 萬，將達查核金額。

政府電子採購網的決標金額多需登入查詢，以上案例以公開新聞與機關網頁為主。
