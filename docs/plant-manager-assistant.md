# WUCA 能協助廠長做哪些事

> 更新日期：2026-10-14　｜　依據：[污水處理廠廠長日常職責分析](https://claude.ai/code/artifact/14fc02b7-99cb-4ce6-b8ed-b3b0880404f9)

廠長的核心任務是讓放流水穩定達標，同時把藥劑、電力與人力用得剛好；出事時要在幾小時內判斷原因、處置並通報。WUCA 的 AI 廠長把日常決策歸納為「**看指標 → 調四個旋鈕（曝氣、迴流、排泥、加藥）→ 留紀錄**」，依事件層級與授權流程自動執行或提出建議。

以下依廠長五大職責分類。每項標示 WUCA 的做法、對應模組，以及仍需要人負責的部分。

## 1. 製程控制

| 廠長工作 | WUCA 怎麼協助 | 模組 | 仍需人 |
| --- | --- | --- | --- |
| 每日看進流與放流水質水量 | 即時彙整線上分析儀、流量計與檢驗報告，異常自動標示 | M1、M3 | — |
| 決定當日排泥量與迴流量 | 依 SV30、MLSS、F/M 與污泥齡趨勢計算建議值，L0／L1 層級自動執行 | M5、M8 | 保守模式下核准 |
| 調整曝氣量 | 依 DO（常見 1–3 mg/L）與進流負荷預測調整鼓風機 | M5、M9 | — |
| 調整加藥量 | 依水質與數位孿生模型最佳化混凝劑、鈣鹽、鹼液用量，兼顧達標與成本 | M5、M8 | — |
| 判斷污泥膨化、上浮、起泡、針狀絮體 | 依 SVI（> 200 常為膨化）、DO、F/M、營養比與影像推論可能原因並提出處置 | M3、M4 | 顯微鏡鏡檢、現場氣味與顏色確認 |
| 預防進流衝擊 | 預測未來 24 小時進流水質水量，必要時提前切換調勻池或事故槽 | M8、M11 | — |

## 廠長常被問的問題，WUCA 都能回答

| 提問者 | 典型問題 |
| --- | --- |
| 主管與管理層 | 放流水有沒有超標風險？本期水污費預估多少？本月藥劑、電費為什麼變高？ |
| 稽查員 | 某時段放流水質如何？申報值為何與查核值不同？自動監測為何中斷？ |
| 操作員 | 今天要排多少泥？加藥量要不要調？這個警報要不要處理？ |
| 製程端 | 本部門今天的排放有沒有造成衝擊？產能增加時廢水廠接得住嗎？ |
| 下水道管理機關 | 納管水質是否符合限值？異常排入時的證據？ |

廠長自己每天問的三個問題，WUCA 首頁直接回答：**現在正常嗎？接下來 24 小時會發生什麼？我該調什麼？**

## 仍需人負責的事

- 顯微鏡鏡檢與現場感官判斷（氣味、顏色、聲音）
- 廢（污）水處理專責人員的法定簽章
- 委外檢測的採樣監督
- 對主管機關的正式通報與回覆
- 預算與人事決策
